## Codebase Patterns
- TypeScript strict mode is enabled in server/tsconfig.json with all strict flags
- ESLint configured with @typescript-eslint/no-explicit-any as error
- Environment variables loaded via dotenv in server/src/config.ts with type-safe getEnvVar helper
- Server exports app, io, httpServer for testing purposes
- Client uses Vite with VITE_ prefix for environment variables
- Socket.io client in client/src/socket.ts with autoConnect: false - call connectSocket() manually
- Discord SDK setup in client/src/discord.ts - use isInDiscord() to check if in Discord iframe
- Tailwind custom colors: prompt-purple, prompt-pink, prompt-green, prompt-black
